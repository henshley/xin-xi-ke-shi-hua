## 地理图型

[H05 美国大选图](#h05) 可用于检查地理位置在读图中起到的作用。主归属和具体编码待原图复核。

### H01

**葡萄酒风味轮。** 既有分析将其归为典型层级型。风味类别由内到外逐层细分，读者沿同一方向向外定位细项，向内追溯归属。待复核标签层数、色彩分组和扇区角度是否对应数值。

### H02

**葡萄串消费图。** 既有分析认为主要任务是比较数值。待复核葡萄粒的数量或面积是否映射数据、串与粒之间的关系是否具有真实的父子层级。

### H03

**疫苗山峰图。** 既有分析认为主要任务是比较数值。待复核高度、面积或其他视觉量如何映射数值，以及山峰造型的叙事作用。

### H04

**生命演化图。** 既有分析记录了两种共存关系：先后演进和分支归属。待复核主阅读任务、分支的含义，以及画面上的间距是否有度量依据。

### H05

**美国大选图。** 既有分析认为图中包含局部地理与归属关系。待复核州或地区的几何位置是否保留、颜色和面积对应哪个变量，以及选票的统计口径。

## 新增案例如何更新文档

1. 在本目录新建一个案例子目录，例如 `cases/H06/`，放一篇分析 Markdown、你提供的原图或出处链接，以及能取得的 CSV、Excel 或制图配置。原始数据缺失时记「待提供」，图面数值确需转录时单独标明来源。
2. 在索引增设案例编号，并从案例分析链接回相关概念定义和呈现类型说明。为 01 中对应概念增加通向该案例的相对文本链接。
3. 用案例中的具体证据补充或修订相关的 A–D 和呈现类型文档，把新原则、设计方法或适用边界连同案例一起提交。图像可见的信息、由图形推断的信息和待补数据分开记录。涉及公式时补齐分母、单位和汇总范围。

### 案例分析记录模板

| 字段 | 填写内容 |
| --- | --- |
| 案例编号与名称 | 稳定编号、图名、来源、作者或发布者（如已知）、原图或出处链接 |
| 读图任务与关系 | 你想让人读懂什么、主数据逻辑、辅数据逻辑、呈现形式 |
| 证据 | 哪个图中位置、标注或数据支持判断，哪些内容待核对 |
| 统计方式 | 统计图形、字段、聚合规则或公式、单位、分母、数据链接 |
| 视觉编码 | 视觉元素 → 数据字段或叙事作用，补上图例、配色和阅读顺序 |
| 信息架构与复用 | 一行数据代表什么、字段及关系、版面阅读路径、可供 AI 作图的输入与约束 |
| 本次文档更新 | 受影响的概念或呈现类型链接、修订内容与对应案例证据 |
