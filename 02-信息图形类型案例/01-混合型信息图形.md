# 混合型信息图形（Mixed Charts）

按本项目约定，混合型把一个或多个统计图形、主题符号、ISO 图形或文字注释放在同一个视觉叙事中。统计图形提供比较的依据，叙事元素说明数值在这个主题中代表什么，并引导阅读。这里沿用你提出的「ISO 图形」，具体指代与例图映射待对照原图确认。

## 怎样读一张案例图

1. 找出主问题、主统计图形和注释。逐项问「它对应了什么字段或结论」。
2. 记录比较方式，例如同尺度的柱长比较、部分占整体的比例、按阶段排列的测量值。补齐单位、分母和筛选条件。
3. 检查符号、主题插图或造型介入的位置。它们可以说明指标的对象、分组或阅读方向。若符号的数量、尺寸承担了数值，记录每个符号代表多少、如何处理零头、尺寸按面积还是长度缩放。
4. 对照原图，把「统计字段 → 图形和尺度 → 叙事元素 → 阅读路径」写成可复用的制图说明。
