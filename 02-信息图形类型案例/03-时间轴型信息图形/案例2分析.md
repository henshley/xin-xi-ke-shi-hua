# 案例2分析｜内燃机的发展历史

![案例2图片：内燃机的发展历史](./案例2图片.png)

## 案例类型判断

- **案例名称：** History of the Internal Combustion Engine（内燃机的发展历史）。
- **五大数据逻辑：** 编年型（Chronological）。
- **17种常用信息图形类型：** 时间轴型信息图形（Timeline Infographics）。
- **核心表达目的：** 展示内燃机技术发展的代表性事件及先后关系。
- **来源：** 用户提供的案例图，作者及原始出处待补。以下年份及技术标题按原图转录，不作历史事实校正。

## A 基本的数据逻辑

以固定的先后顺序作为唯一主干组织维度，串联内燃机技术发展的十个主要节点。

- 单向性：沿统一方向展开。
- 不可逆性：客观先后关系不能随意颠倒；倒向阅读不等于改变客观顺序。
- 强制顺序性：节点相对位置由数据本身决定，而不是设计者临时排序。
- 单维主导：年份是主组织字段。
- 节点独立性：各节点具有相对完整的事件内容，但其相对顺序受到主干约束。
- 序列延展性：可插入或补充事件，仍须遵守既定顺序。

原图主要年份从上至下为1807、1859、1870、1877、1893、1898、1914、1950、1970、2000，呈固定递增序列。每个节点的标题、说明、照片和注释只是同一事件的不同属性，并未进一步形成真正的父子分类层级，因此不属于编目型。顶部辅助说明也不改变主体的编年结构。

## B 使用了怎样的统计图形

借用时间轴图（Timeline）的组织形式，并非严格的定量统计图形。RAWGraphs 中没有与这一图文叙事式时间轴完全对应的标准图形，不强行归为折线图或甘特图。

| 组织或计算方法 | 案例表现 |
| --- | --- |
| 顺序排序 | 年份递增，保持固定的事件顺序 |
| 节点提取 | 从技术发展过程中选取代表性里程碑 |
| 离散数据展示 | 每个技术事件作为一个独立节点 |
| 数据映射 | 年份与名称、说明、机械图像、注释相互对应 |
| 刻度标记 | 主轴两侧配置辅助年份 |
| 非等比例排列 | 节点间距以图文版式为主，并非真实时间差的统一比例映射 |

1807—1859与1870—1877的时间间隔相差明显，画面间距并不遵循同一时间比例。因此属于非等比例顺序型时间轴，重点是先后关系，不是精确时长；没有求和、平均值、占比等统计计算。若未来需要表达精确时间差，必须采用统一尺度或明确标识断轴。

## C 视觉编码

| 视觉元素 | 具体表现及功能 |
| --- | --- |
| 点 | 大型白色年份数字代替传统节点圆点 |
| 线 | 纵向连续主轴串联技术事件，表达先后关系 |
| 面 | 红色纵向色带扩大主轴的视觉权重，形成共同区域 |
| 体 | 黑白机械图像展示真实形态与体积感，不代表数值大小 |
| 符号 | 发动机、汽车、飞轮等代表性形象指代技术事件 |
| 位置 | 纵向位置表达顺序，横向位置组织图文 |
| 大小 | 年份、标题、图像大小建立视觉主次，而非定量映射 |
| 色彩 | 红、黑、白、灰区分视觉功能、强调关键内容 |

### 字体系统
大型白色粗体年份（一级）；红黑双色窄体标题（二级）；小字号正文（三级）；浅灰年份刻度和小注释（四级）。紧凑的窄体英文字体呼应工业机械主题。

### 色彩系统
近似参考色：红色 #E51C23（主轴、关键词）；白色 #F5F5F3（背景、年份）；黑色 #202020（文字、机械图像）；灰色 #A5A5A5（辅助刻度及细节）。颜色承担视觉引导与强调作用，不代表不同数据类别。

### 版式系统
纵向主轴、非对称平衡、左右交错、重复模块。轴带略偏画面左侧，两侧图文通过交替排列形成节奏。

### 图像辅助系统
黑白机械图像、红色单色机械图像、局部放大、裁切出血、图像叠加。黑白机械图承担主要信息传达，外围红色图形辅助主题强化和视觉平衡。

### 图译系统
将二冲程、四冲程、柴油发动机、V8等抽象技术概念转换为具有代表性的机械产品形态。

## E 视觉叙事架构

单向线性叙事＋技术演进叙事＋左右交错式节点叙事。

- 主题导入：标题、内燃机应用领域和重要性。
- 主干叙事：从上至下按固定顺序展开技术发展节点。
- 局部叙事：每个节点以年份定位、标题概括、正文解释、图像展示、注释补充。
- 阅读引导：红色纵向主轴、大型年份与辅助刻度形成稳定的视线方向。
- 节奏控制：图文左右交替，机械图像大小与位置变化打破长幅阅读的单调。
- 技术演进：由早期技术、结构改进、产品应用、能源变化延伸至现代技术；这种概括不意味着各事件之间均已证实具有直接因果关系。

## 格式塔原理与设计经验

- 良好连续性：连续红色轴带引导纵向阅读，是最核心的视觉组织原则。
- 相似性：年份字体、图像风格与重复模块保持统一。
- 接近性：年份、标题、文字及对应图像邻近排列。
- 图底关系：红色轴带和黑色图像与白色背景形成清晰区分。
- 共同区域：主要年份被统一色带包围，强调主干归属。

**通用规律：** 编年型信息图形的本质是数据固有的强制顺序，而非时间轴的外形。轴线可以变为色带、圆点可以变为数字、事件可以变为具象图像；视觉形式可变，数据的固定先后关系不能改变。非等比例时间轴可以表达顺序，但不能让读者把视觉间距理解为精确时间差。
