# 地理图型信息图形概念定义

## A 基本的数据逻辑

用实际地理位置或明确的空间关系组织信息。点位、区域、路线、邻接、距离或分布决定图件怎样被理解。一条记录可以关联一个地理单元，也可以描述两个地理位置之间的连通或流动。

**判断方法。** 想象互换两个地点的位置。如果会改变对分布、邻接或路线的判断，空间关系承担了核心信息。美国大选图中地理位置对读图有多重要，待原图复核。

## B 统计图形与计算

点位图标注位置，比例符号地图可比较总量，分级设色图可比较按人口、面积或其他口径标准化后的数值，流向图可对应起点与终点。按区域计算比率时，用该区域的指标数除以对应基数，并标出单位。分级色还需记录断点、分级方法和缺失值规则。

## C 视觉编码

点表示地点，线表示路线或流向，面表示地理单元。色相区分类别，渐进色表达数值的高低，圆面积可映射总量。给关键位置加标签并说明图例。涉及距离、面积判断时记录所用投影或度量口径。无数据区域用专门图例表示。

## D 数据与信息架构

每行是一个点位、区域或一条流向，包含地理 ID 或坐标、几何类型、指标和单位。区域数据以稳定区划 ID 与地理边界匹配，并记录边界版本。流向数据保留起终点 ID 与流量。图面先交代范围及图例，再引导读者看空间分布和重点位置。
