# 字母表型信息图形概念定义

## A 基本的数据逻辑

独立条目以名称对应的字母顺序组织。先用首字母找分区，再在分区内按完整检索键定位，顺序受所选语言及排序规则约束。同首字母的条目按后续字母比较。同一个字母分区可以容纳多个主题的条目。

**判断方法。** 用一个条目名称试查。若知道如何拼写或转写就能定位，并且改名后条目会按新键移动，这套结构就依赖字母索引。

## B 统计图形与计算

字母索引和分组条目表可直接展示排序结果。要比较每个字母下的条目数时，可用按字母排列的条形图。频数按排序键的首字母分组计数，同名条目按 ID 保留，重复记录按项目约定去重。条目数量用于描述索引分布。

## C 视觉编码

用大写字母、边栏或区块标题标出检索入口，条目名称使用统一字阶和对齐方式。条目图标可以补充主题。色彩突出当前分区或另一个已说明的字段。数量有必要呈现时，再用条形长度等明确编码。

## D 数据与信息架构

每行一个条目，保留 `item_id`、`display_name`、`sort_key`、`initial` 和说明。明确检索键采用原文、拼音或其他转写规则，并说明大小写、重音字符、数字和同名条目的处理。阅读路径为「字母入口 → 组内排序 → 条目」。
