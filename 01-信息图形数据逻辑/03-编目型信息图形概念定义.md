# 编目型信息图形概念定义

## A 基本的数据逻辑

以可查找的独立条目为单位，用类目、主题或属性建立检索入口。条目共享一组描述字段，可从多个属性筛出同一条记录。有些编目体系也用父子类目，阅读的主任务仍是找到条目并查看同一类下有哪些记录。

**判断方法。** 假设读者只知道一个特征，问他能否按这个特征定位条目。再检查分类依据能否适用于整个目录。

## B 统计图形与计算

卡片、目录和矩阵可表达归档信息。要展示各类的条目数，可按类别计数并用条形图。要看两个属性如何交叉，可用矩阵或热力图记录各组合的计数。允许一个条目拥有多个标签时，每个标签单独统计，整体计数按条目 ID 去重。

## C 视觉编码

用分组区域表示目录入口，醒目标记表示类别，条目统一图标和对齐方式。用固定位置或颜色高亮重要属性，标签文字保留具体含义。只有记录了数量字段并说明单位后，才用长度、面积或重复符号表达数量。

## D 数据与信息架构

每行是一个条目，包含 `item_id`、`name`、`category`、必要属性和来源。多类目归档可单列条目 ID 与类目 ID 的对应表。图面沿「检索入口 → 类目或筛选结果 → 条目 → 详情」展开，支持同一条目被多个入口找到。
